# UI 重设计规格文档 — Terminal Dark

**日期：** 2026-05-08  
**项目：** time-blog-web（小花的日记本）  
**方案：** Terminal Dark — 现代科技风，深黑背景 + 青绿点缀

---

## 背景与目标

当前博客 UI 为紫蓝色渐变风格，带有雪花动画、背景图切换、毛玻璃效果等大量装饰性元素。本次重设计目标：

- 全面替换视觉语言，走克制的技术美学路线
- 去掉所有装饰性动画和背景切换功能
- 建立清晰的色彩系统和排版规范
- 保留所有现有功能和路由结构，只改 UI 层

---

## 一、设计语言 & 色彩系统

### 调色板

| 用途 | Token | 值 |
|------|-------|----|
| 主背景 | `--bg-primary` | `#0a0a0f` |
| 次背景/卡片 | `--bg-secondary` | `#111118` |
| 边框 | `--border-color` | `#1e1e2e` |
| 主文字 | `--text-primary` | `#e2e8f0` |
| 次文字 | `--text-secondary` | `#94a3b8` |
| 三级文字 | `--text-tertiary` | `#475569` |
| 主强调色 | `--color-accent` | `#00d4aa` |
| 次强调色 | `--color-accent-2` | `#38bdf8` |
| 危险/置顶 | `--color-danger` | `#f87171` |
| 推荐/金 | `--color-warning` | `#fbbf24` |

深色主题为唯一主题（移除浅色/自动模式，或保留但以深色为默认）。

### 字体

```css
font-family: 'JetBrains Mono', 'Fira Code', 'PingFang SC', 'Microsoft YaHei', monospace, sans-serif;
```

- 标题：`font-weight: 700`
- 正文：`font-weight: 400`，行高 `1.8`
- 代码块：`JetBrains Mono`，背景 `#0d1117`，青绿语法高亮

### 圆角

| 元素 | 圆角 |
|------|------|
| 卡片 | `6px` |
| 按钮/标签 | `4px` |
| 输入框 | `4px` |
| 头像 | `50%` |

### 阴影 & 边框

- 默认状态：`border: 1px solid #1e1e2e`，无 box-shadow
- Hover 状态：`border-color: #00d4aa` + `box-shadow: 0 0 12px rgba(0, 212, 170, 0.2)`
- 不使用大面积渐变背景

## 二、布局结构

### 全局布局

```
┌─────────────────────────────────────────┐
│  Header（固定顶部，64px 高）            │
│  Logo | 导航链接 | 主题切换 | 用户头像  │
├─────────────────────────────────────────┤
│                                         │
│  <router-view>（页面内容区）            │
│  最大宽度 1200px，水平居中，padding 24px│
│                                         │
├─────────────────────────────────────────┤
│  Footer（简洁，单行信息）               │
└─────────────────────────────────────────┘
```

### 移除的全局元素

- 雪花动画（50 个 DOM 节点）
- 背景图/视频切换器
- 公告滚动栏
- 宇宙星辰装饰

### Header 重设计

- 背景：`#0a0a0f` + `border-bottom: 1px solid #1e1e2e`
- 滚动后：`backdrop-filter: blur(8px)` + `background: rgba(10,10,15,0.85)`
- Logo：纯文字 + 青绿下划线，去掉圆形渐变背景和脉冲动画
- 导航：文字链接，active 用 `#00d4aa`，hover 用 `#38bdf8`
- 右侧：主题切换图标 + 用户头像，无多余装饰

### 首页布局

```
┌─────────────────────────────────────────┐
│  Hero 区（全宽，200px 高）              │
│  大标题 + 一句话介绍 + 统计数字         │
├─────────────────────────────────────────┤
│  文章网格（3列，响应式降至1列）         │
│  每张卡片：封面图 + 标题 + 摘要 + 元信息│
└─────────────────────────────────────────┘
```

### 文章卡片规格

- 背景 `#111118`，边框 `#1e1e2e`，圆角 `6px`
- Hover：边框变青绿 + `translateY(-2px)`，200ms ease
- 封面图：`aspect-ratio: 16/9`，无圆角，`object-fit: cover`
- 标签：小胶囊，青绿描边，无填充，`font-size: 11px`

## 三、核心页面设计

### 文章详情页

- 内容区最大宽度 `760px`，居中，左右 padding `24px`
- 标题区：文章标题（28px，700）+ 元信息一行（日期、分类、阅读数）+ 标签
- 正文：行高 `1.8`，段落间距 `1.5em`
- 代码块：背景 `#0d1117`，青绿语法高亮，圆角 `6px`
- 目录：右侧固定浮动，宽度 `220px`，屏宽 > 1200px 时显示
- 评论区：简洁表单，无多余装饰

### 文章列表页

- 左侧筛选栏（`240px`）+ 右侧文章列表
- 筛选栏：分类树 + 标签云，背景 `#111118`，`border-right: 1px solid #1e1e2e`
- 列表卡片：横向布局，左图（`160px`）右文，比首页卡片更紧凑

### 其他页面

| 页面 | 设计要点 |
|------|---------|
| 分类/标签 | 统一页面头部：标题 + 简短描述，青绿左边框装饰 |
| 说说 | 时间轴布局，左侧时间线用青绿细线 |
| 相册 | 瀑布流网格，hover 显示图片描述遮罩 |
| 友链 | 卡片网格，头像 + 站名 + 描述，hover 边框发光 |
| 关于 | 单列，头像居中，内容分块 |
| 登录/注册 | 居中卡片 400px，背景主色，卡片 `#111118` + 青绿边框 |

## 四、动效 & 交互

### 保留的动效

| 触发 | 效果 | 时长 |
|------|------|------|
| 卡片 hover | 边框变青绿 + 上移 2px + 光晕 | 200ms ease |
| 链接 hover | 颜色过渡到 `#00d4aa` | 150ms |
| 按钮 hover | 背景填充青绿，文字变黑 | 150ms |
| 页面切换 | fade in，opacity 0→1 | 200ms |
| 图片加载 | 骨架屏 shimmer（深灰闪烁） | 持续到加载完成 |
| Header 滚动 | backdrop-filter blur 激活 | 即时 |

### 移除的动效

- `float`、`pulse`、`bounce`、`fall`（雪花）、`orbit` 所有 keyframe 动画
- Logo 脉冲效果
- 背景切换过渡动画

### Element Plus 主题覆盖

- 主色：`#00d4aa`
- 所有圆角降至 `4-6px`
- 输入框、按钮、分页、对话框跟随新主题色
- 通过 SCSS 变量覆盖 Element Plus 默认主题

## 五、响应式断点

| 断点 | 布局变化 |
|------|---------|
| > 1200px | 文章详情目录显示，3列网格 |
| 768px - 1200px | 2列网格，目录隐藏 |
| < 768px | 单列，Header 汉堡菜单，筛选栏折叠 |

## 六、实现范围

### 需要修改的文件

| 文件 | 改动内容 |
|------|---------|
| `src/styles/global.scss` | 全量替换 CSS 变量和全局样式 |
| `src/App.vue` | 移除雪花、背景切换、公告栏 |
| `src/components/Header.vue` | 重设计导航栏 |
| `src/components/Footer.vue` | 简化底部 |
| `src/views/Home.vue` | Hero 区 + 文章网格重设计 |
| `src/views/ArticleList.vue` | 筛选栏 + 列表卡片重设计 |
| `src/views/ArticleDetail.vue` | 文章内容区 + 目录重设计 |
| `src/views/Login.vue` | 登录卡片重设计 |
| `src/views/Register.vue` | 注册卡片重设计 |
| 其余 views | 统一页面头部样式 |

### 不改动的内容

- 所有 API 调用逻辑（`src/api/`）
- 路由结构（`src/router/`）
- 状态管理逻辑（`src/stores/`）
- 组件功能逻辑，只改样式层

- [ ] 所有页面在深色背景下文字对比度 ≥ 4.5:1（WCAG AA）
- [ ] 移动端（375px）所有页面可正常浏览
- [ ] 文章详情页代码块正确显示青绿高亮
- [ ] Element Plus 组件（输入框、按钮、分页）跟随新主题色
- [ ] 无残留的雪花/背景切换/公告滚动代码
- [ ] `npm run build` 无类型错误
